# Tripleten web_project_around_express

## Descripción

Este proyecto consiste en una API REST desarrollada con Node.js, Express y MongoDB. La API permite gestionar usuarios y tarjetas de la aplicación Around.

Los usuarios pueden consultar y actualizar su información, mientras que las tarjetas pueden ser creadas, eliminadas y recibir o quitar likes.

## Funcionalidades

### Usuarios

- Obtener la información de los usuarios.
- Obtener un usuario por su ID.
- Crear nuevos usuarios.
- Actualizar la información del perfil.
- Actualizar el avatar del usuario.

### Tarjetas

- Obtener todas las tarjetas.
- Crear nuevas tarjetas.
- Eliminar tarjetas.
- Añadir likes a las tarjetas.
- Eliminar likes de las tarjetas.

## Tecnologías utilizadas

- Node.js
- Express.js
- MongoDB
- Mongoose
- JavaScript
- ESLint
